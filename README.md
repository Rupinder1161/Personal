# MoneyHub

A personal finance application for tracking spending, rent, shared expenses, debts, and savings.

## Workspaces

- Frontend: `frontend/`
- Backend API: `backend/`

## Quick start

Frontend:

```bash
cd frontend
npm install
npm run dev
```

Backend:

```bash
cd backend
npm install
cp .env.example .env
npm run dev
```

## Build verification

The app has been verified with production builds:

- Frontend: `cd frontend && npm run build`
- Backend: `cd backend && npm run build`

## Deployment targets

- Frontend: Netlify
- Backend: Render
- Database: Render PostgreSQL
